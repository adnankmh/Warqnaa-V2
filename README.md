# Warqnaa V0.4.9+209 — R9 Visual Revolution & Architecture Cleanup

الإصدار الحالي: **0.4.9+209**

R9 هو إصدار إعادة بناء للهوية والتجربة فوق محركات R8.1 المستقرة.

## ما تغير
- Design System موحد في Flutter وLaravel.
- Home/Lobby جديد في التطبيق والموقع.
- الطاولات اتجاهية فقط: Portrait طولية وLandscape/Web عرضية، والصورة تغطي السطح كاملاً.
- المنتج أصبح عربي/إنجليزي فقط في واجهات المستخدم الأساسية.
- المتجر ينظف الترجمات القديمة ويعطل التكرار المطابق بدون حذف تاريخ المشتريات.
- هوية البوت واضحة BOT مع مظهر أهدأ وأكثر اتساقاً.
- Live Ops foundation للإعلانات المكافِئة والعروض اليومية/الأسبوعية/الشهرية/السنوية.
- Asset Audit فعلي مع إزالة أول دفعة من التكرارات الآمنة داخل Flutter.
- 6 ثيمات منسقة بدل قائمة طويلة من ثيمات متشابهة.
- تشغيل Windows موحد عبر 8007/8008/8009/8010 وفحص R9 واحد.

ابدأ من `START_WARQNA_WINDOWS.bat` واختر 8007.
