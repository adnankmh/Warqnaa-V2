# Warqnaa V0.4.5+201 — Gameplay & Admin Pro

- ترتيب يدوي محفوظ للهاند والبناكل بالسحب والإفلات.
- ترتيب تلقائي: سنك، ديناري، بستوني، كبة؛ ومن الأعلى للأقل داخل النوع.
- توزيع طرنيب balanced_playable متماثل على الجميع (لا يفضّل مقعدًا أو مستخدمًا).
- واجهة ويب محسنة لعرض 100%، طاولات متجاوبة ودردشة مرنة.
- صور البروفايل دائرية مع معاينة التعديل.
- لوحة الإدارة غير sticky، مع تفويض صلاحيات للمدير Abd.
- Adnan مدير رئيسي برصيد إدارة غير محدود وامتلاك كامل للمقتنيات النشطة.
- Abd / 123AbdAbd مدير مفوض، رصيد 10^16 توكن، دون صلاحيات تصميم الموقع أو قواعد المحركات افتراضيًا.
- حسابات التجربة أصبحت >= 1,000,000 توكن.
- مقتنيات R201 جديدة: طاولات متحركة/شخصية، ظهر ورق، إيموجز، شارة، غلاف وثيم.

## إضافات الإغلاق النهائي لـ V201
- Flutter: سحب مطوّل وإفلات لإعادة ترتيب يد الهاند والبناكل وإرسال الترتيب إلى المحرك بدل ترتيب بصري محلي فقط.
- Flutter Offline Tarneeb: مزايدة 7–13/تمرير ثم اختيار الطرنيب، بدل الدخول المباشر إلى اللعب.
- سياسة No-Fresh للطرنيب: إعادة توزيع الجولة ككل حتى يتحقق حد جودة متماثل لجميع المقاعد؛ لا تعتمد على اسم المستخدم أو المستوى أو الشراء أو الباشا.
- دولاب المكافآت: 8 قطاعات فعلية متنوعة كما في المتطلبات الجديدة.
- مقتنيات R201 الأسطورية أصبحت مرتبطة بكلاس التفعيل الحقيقي داخل غرفة اللعب: حوت متحرك، أجنحة ملكية، طاولة توقيع باسم اللاعب، ظهر عنقاء متوهج، غلاف مجرة، وثيم منتصف الليل الذهبي.
- حساب Abd مدير مفوض وحساب Adnan مدير رئيسي مع امتلاك كامل المتجر بعد Seeder.
- 12 لاعب اختبار بمستويات مختلفة وبحد أدنى 1,000,000 توكن لكل حساب.
