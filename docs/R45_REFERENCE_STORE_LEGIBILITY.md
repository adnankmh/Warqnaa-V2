# R45 — Reference store legibility

R45 is a focused native Flutter readability increment based on the merged R44
checkpoint.

## Scope

- Keep the sky-blue, royal-blue and gold reference treatment.
- Preserve the real visible product catalogue, live controller prices and the
  existing product-preview and rewards routes.
- Replace the three compressed phone-width offer columns with a horizontal
  136px item rail below 420px, while retaining the equal-column desktop row.
- Raise the remaining category and reward detail copy in this surface to a
  12px floor in Arabic and English.
- Add narrow bilingual widget coverage, source-level Laravel coverage and R7
  runtime screenshots.

No economy, entitlement, prize, game-engine or server-authority behavior is
changed. GitHub Pages remains a static client demonstration: no public Laravel
multiplayer service or `WARQNA_API_URL` is configured. Store-production signing,
payment credentials and physical-device validation remain external inputs.
