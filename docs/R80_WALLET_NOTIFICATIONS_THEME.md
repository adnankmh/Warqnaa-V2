# R80 — bilingual themed wallet and notifications

R80 applies the selected cosmetic theme to the wallet balance, transaction list
and empty-notification state. The built-in notification and transaction samples
now render in Arabic or English, including their dates, without modifying the
stored amounts, transaction signs, notification records or server payloads.

Green income/success and red spending/loss indicators remain semantic. Token
balances, purchase settlement, transfer fees, permissions, networking and server
authority are unchanged.

Arabic and English widget coverage exercises dark crimson and light emerald
themes at 390×844. R7 captures notifications and wallet states for all four
locale/theme combinations for manual review.
