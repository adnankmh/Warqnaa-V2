# R77 — room entry theme propagation

R77 applies the selected cosmetic theme to the remaining room-entry accents:
the available-room connection marker, join-by-code lock, create-room mode marker,
empty-room text, and voice privacy notice. Connected and voice-enabled states
retain a semantic green signal blended toward the active theme accent.

Room discovery, room codes, passwords, voice selection, navigation callbacks,
server authority, game engines, networking, permissions and economy are
unchanged.

emerald themes at 390×844. R7 captures join-code and voice-room states for all
four locale/theme combinations for manual review.
