# R89 — bilingual room lobby

R89 localizes the server-rendered room list and room-creation flow for Arabic
and English. Room headings, status badges, leader statistics, join controls,
empty state, room type, voice fee, seat count, speed, owner-kick permission,
spectator privacy, XP exit policy, minimum level, target score and modal
controls now follow the active locale and page direction.

The change also adds accessible labels for private-room passwords and the modal
close control. Existing form names, values, routes, token price, XP amount,
permission checks, room engines, networking, hidden cards and economy behavior
remain unchanged.
