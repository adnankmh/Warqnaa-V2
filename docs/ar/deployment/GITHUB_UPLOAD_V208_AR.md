# رفع Warqnaa V208 إلى GitHub

1. افتح المجلد في GitHub Desktop.
2. تأكد أن الفرع `main` وأن `git status` نظيف بعد Commit.
3. نفّذ Commit بعنوان مثل: `Warqnaa R8 engine integrity release`.
4. Push origin.
5. راقب Actions: Backend CI, Production Release Gate, Flutter Android, Flutter Web, Flutter iOS.
6. لا تعتبر الإصدار جاهزًا للنشر إذا فشل أي Gate إلزامي.

R8 يضيف اختبارات مستقلة لقواعد Tarneeb/Hand/Banakil، واختبار multi-step playthrough لجميع المحركات، بالإضافة إلى العقود التاريخية السابقة.
