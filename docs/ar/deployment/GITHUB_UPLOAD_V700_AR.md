# R7 — رفع المصدر والتحقق

يعتمد الإصدار على R6.5 المدمجة في main. تُرفع تغييرات R7 في فرع مراجعة، ثم تُفحص مسارات Backend وProduction وFlutter Web وAndroid وWindows وR7 runtime.

نجاح R7 runtime ينتج تقريرًا وصور واجهة من حسابات مؤقتة، وحزمة مصدر كاملة مع SHA-256 ومثبت مرحلي. لا تُرفع بيانات الاختبار الخاصة أو قواعدها أو سجلات HTTP الخام. تحفظ الحزمة رقم الالتزام، ويقرأ المثبت نسخة الحزمة بدل أرقام ثابتة.

لا يُعتمد النشر الإنتاجي بمجرد نجاح CI. يجب إعداد HTTPS والجدولة والطوابير والإشعارات ومفاتيح الدفع وتوقيع المتاجر عبر بيئة النشر، وفحص الأجهزة المطلوبة. لا يوجد نشر إنتاجي جديد في هذه المرحلة.
