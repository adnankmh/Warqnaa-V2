# Warqnaa R7 Elite – ملخص التعديلات

## أهم ما تم في R7

1. **الطاولات أصبحت اتجاهية فقط**
   - تم إلغاء الاعتماد على شكل الطاولة المربعة في الصفحات الأساسية.
   - الواجهة الآن تتجاوب حسب اتجاه الشاشة: **طولي على الهاتف** و **عرضي عند التدوير/الويب**.
   - تحسينات CSS للطاولة، منطقة الوسط، ومعلومات الجولة.

2. **إضافة خيار جولة واحدة عند إنشاء اللعبة**
   - متاح الآن في التطبيق.
   - يرسل أيضًا إلى خادم Laravel داخل حالة الغرفة.

3. **تحسين واجهة الطرنيب محليًا**
   - إظهار: صاحب الطلب، نوع الطرنيب، آخر لَمّة، ونمط المباراة.
   - إظهار آخر كرت تم لعبه لكل لاعب.
   - إظهار عدد اللمّات لكل لاعب، مع صافي نقاط الجولة لكل فريق.
   - الاستمرار التلقائي مع توقيت الجولة المحسّن.

4. **تحسينات غرف الويب**
   - إزالة `square-table` من القالب الأساسي للغرفة.
   - إضافة بطاقات حالة وسطية توضّح نمط الغرفة والسرعة وآخر حركة والطرنيب.

5. **المنافسات**
   - توسيع Presets في الخادم: دوري ملكي، تحدي ليلي، كأس المحترفين، وغيرها.
   - إضافة تصنيفات ومصفوفة جوائز داخل الإعدادات.

6. **دولاب الحظ والصندوق المجاني**
   - الواجهة الخلفية بالفعل تعمل كل **12 ساعة**.
   - تم تصحيح `packStatus()` ليعرض التوقيت الصحيح كل 12 ساعة بدل مرة يوميًا.

## ملاحظات تشغيل
- الحزمة الحالية مبنية فوق **R6** وتنتج نسخة **R7 Elite**.
- إن أردت مزيدًا من التطابق مع جواكر داخل محركات الهاند/البناكل/الطرنيب على مستوى الخادم خطوة بخطوة، فهذه جاهزة كمرحلة **R8 Rules Audit** مع اختبارات أوسع لكل لعبة.
