# Warqnaa R11 — 0.6.0+230

هذه هي النسخة النهائية لمرحلة **R11 Social World**، مبنية مباشرة فوق R10.1 Build 221 وتحافظ على جميع عقود R8 وR9 وR9.1 وR10 وR10.1.

## ما الجديد

- عالم اجتماعي حي: موجز، متابعة، اكتشاف لاعبين، فعاليات وحضور.
- Clubs 2.0 بعقد API للموبايل مع الدوريات والإعلانات والنشاط والصلاحيات.
- مدرجات مشاهدة Read-only لا تنضم إلى مقاعد اللعب ولا إلى WebRTC.
- الإرسال للمشاهد يخفي الأيدي وترتيب الرزمة وكلمات السر وRNG وبيانات المحرك الخاصة بصورة Recursive.
- إعادة مباراة آمنة مع Frames عامة وبصمة SHA-256 وسياسة ظهور Public/Friends/Private.
- هدايا متحركة اجتماعية فقط؛ لا تؤثر في التوزيع أو الحركة أو النتيجة.
- مركز خصوصية موحد للملف والظهور والرسائل والدعوات والمتابعة والصوت والمشاهدة والإعادات.
- Admin Social World على الويب وFlutter مع Audit Log للإعدادات والإشراف.

## تشغيل سريع

1. فك **Full Repository** في مجلد جديد، أو طبّق **R11 Upgrade** فوق النسخة B221 فقط.
2. على Windows شغّل `START_WARQNA_WINDOWS.bat` واختر المنفذ 8007–8010.
3. شغّل migrations؛ مشغّل Windows ينفذها تلقائيًا.
4. قبل GitHub شغّل `CHECK_WARQNA_WINDOWS.bat`.
5. لا تنسخ `.env` من حزمة أخرى ولا ترفع أي أسرار إلى GitHub.
6. في الإنتاج شغّل `php artisan schedule:run` كل دقيقة؛ فهو ينفذ تنظيف المشاهدين والحضور والإعادات المنتهية.

## عقد الخصوصية الثابت

المشاهد لا يستطيع تنفيذ Game Action، ولا يدخل Voice Room، ولا يرى Hand/Deck/Legal Actions/Private Chat/Password/Secret/Token/RNG. الإعادة تحفظ الحالة العامة فقط، ولا تسجل الصوت أو المحادثة الخاصة.
