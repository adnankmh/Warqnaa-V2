# ملاحظات إصدار Warqnaa 1.0.2+262

## الجديد

- مركز أمان فاخر ومتجاوب في الموقع.
- صفحة أمان ثنائية اللغة داخل إعدادات تطبيق Flutter.
- تغيير البريد وكلمة المرور للمستخدمين والمديرين Adnan وAbd.
- تأكيد كلمة المرور الحالية وقواعد كلمة مرور قوية.
- إعادة التحقق من البريد وإغلاق الجلسات الأخرى تلقائيًا.
- منع نموذج البروفايل القديم من تجاوز حماية بيانات الدخول.
- منع Seeders من إعادة بيانات المدير بعد تغييرها.
- منع تعبئة بيانات Adnan الافتراضية أو تفعيل حساب المدير التجريبي أوفلاين في Production.

## ثبات CI

- الحفاظ على إصلاح SQLite `:memory:`.
- GitHub Pages اختياري؛ فشل الصلاحية لا يمنع بناء Web artifact.
- الحفاظ على فصل ميزانيات مصدر `public` وناتج البناء والتحقق من جميع بصمات R10.
