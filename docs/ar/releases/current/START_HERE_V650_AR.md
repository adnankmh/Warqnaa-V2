# Warqnaa R6.5 Build 650 — تشغيل وإدارة وتجهيز الإصدار

نسخة كاملة تراكمية فوق R6.4 Build 640، وتتضمن محتوى R6.1 والطاولات وظهور الورق وواجهات الألعاب والمجتمع والمنافسات السابقة.

## ما أُنجز

- إصلاح اسم الغرفة الفارغ، وقراءة السعة الصحيحة، ونتائج البحث المتأخرة، وإرسال طلب الانضمام مرتين.
- إدارة المجموعة: إنشاء ودعوة برقم اللاعب وقبول برمز ومغادرة، مع انتقال القيادة للعضو التالي.
- منع الانضمام دون دعوة، وتكرار إشعارات الدعوة، والانضمام لمجموعتين، وتقليص السعة تحت عدد الأعضاء.
- حجب البريد ومعلومات الحساب الخاصة عن استجابة المجموعة.
- مركز تشغيل للويب والتطبيق يعرض قاعدة البيانات والتخزين والجدولة والتوافق وHTTPS ووضع التطوير. الوصول للمدير الرئيسي أو مدير يحمل صلاحية security.
- مثبت Windows يفحص الحزمة والمتطلبات ويبني في مجلد مؤقت قبل تبديل النسخة.
- تشغيل نسخة Flutter Web المبنية مع الخادم والجدولة، دون اشتراط متصفح Chrome.

## التشغيل

استخرج الحزمة الخاصة خارج D:\warq، ثم شغّل INSTALL_WARQNAA_R65_AUTO.bat.
المتطلبات: Windows وD: ومساحة 6GB وPHP 8.2+ بإضافات SQLite وPDO SQLite وmbstring وDOM وOpenSSL وPython 3.10+.
يتولى المثبت تنزيل Composer بعد التحقق من توقيعه وFlutter 3.44.0 عند غيابه إذا توفر Git والإنترنت.

الترقية التلقائية تدعم قاعدة SQLite محلية. تتوقف قبل تعديل قواعد MySQL/PostgreSQL أو بيئة الإنتاج. عند وجود تشغيل قديم لا يمكن التحقق من عملياته بأمان، أغلق نوافذ Warqnaa القديمة وأعد التشغيل.

بعد التثبيت: START_WARQNA_WINDOWS.bat لإعادة التشغيل، وscripts/windows/current/STOP_WARQNA_WINDOWS.bat للإيقاف.
تظهر النتيجة في INSTALLATION_RESULT.json والسجل في INSTALLATION_LOG.txt بجانب المثبت.

## البيانات والترقية

النسخة السابقة تبقى في D:\warq-backup-TIMESTAMP. يحفظ المثبت .env والبيانات والمرفوعات وبيانات Git. قاعدة SQLite تُنسخ باستخدام SQLite backup API للتحقق من سجلات WAL. لا تُعاد تهيئة قاعدة المستخدم، ولا يُعاد ضبط حساب Adnan الموجود، ولا يُعاد seed خلال الترقية حتى لا تُمحى تعديلات المتجر.

إذا فشل التبديل يعيد المثبت الملفات السابقة عندما يستطيع؛ قد يلزم تشغيلها مجددًا. إذا فشلت الاستعادة أيضًا يُبقي مسار النسخة الاحتياطية في تقرير النتيجة ولا يحذفها.

## حدود التحقق

نجاح فحوص المصدر لا يساوي نجاح Flutter analyze أو PHPUnit. المثبت يطلب نجاح فحوص التشغيل المحددة قبل الترقية. اختبارات الواجهة البصرية على الأجهزة والتزامن بين عدة أجهزة والتوقيع والنشر للمتاجر لم تُعتمد هنا.
هذا إصدار R6.5 وتجهيز للخطوة R7، وليس إعلانًا باكتمال نشر إنتاجي عالمي أو ملف APK/IPA مُوقّع.
