# Warqnaa R12 — 0.7.0+240

هذه النسخة النهائية لمرحلة **R12 Competitive Arena**، مبنية مباشرة فوق R11 Build 230 وتحافظ على R8 وR9 وR9.1 وR10 وR10.1 وR11 كاملة.

## ما الجديد

- Ranked Matchmaking خادمي بلا Bots، مع نافذة MMR تتوسع تدريجياً وتوافق ثنائي الجانب واحترام الحظر والمنطقة.
- MMR عام وتصنيف مستقل لكل لعبة، Placement Games، Soft Reset، سلاسل انتصارات وعقوبة انسحاب.
- مواسم تنافسية، ثمانية Tiers، Leaderboards عالمية/دولية/أندية، لقطات ترتيب ومكافآت موسمية ذرية.
- بطولات متعددة المراحل بجداول حتمية، غرف رسمية من المحرك الخادمي، وتأهل تلقائي بعد اعتماد النتيجة.
- سعات جداول صحيحة للمقاعد الفردية والزوجية، مع غرف حسم للتعادل واستبدال موثّق للمباراة الملغاة.
- كأس عالمي وبطولات أندية ودول، مع حدود MMR وقفل التسجيل والانسحاب بعد بناء الجدول.
- صرف جائزة النهائي مرة واحدة فقط؛ مباريات الأدوار المبكرة لا تستطيع تحرير الجائزة.
- Anti-cheat Review يعلّق MMR والتأهل حتى موافقة مدير مخوّل.
- Competitive Arena وAdmin Competitive متكاملان على الويب وFlutter.
- استرداد تشغيلي مقاوم للأعطال: تعطل سجل واحد لا يوقف معالجة بقية المباريات، مع Exit Code واضح للمراقبة.

## تشغيل سريع

1. فك **Full Repository** في مجلد جديد، أو طبّق **R12 Upgrade** فوق R11 Build 230 المطابق فقط.
2. على Windows شغّل `START_WARQNA_WINDOWS.bat` واختر المنفذ 8007–8010.
3. شغّل migrations؛ مشغّل Windows ينفذها تلقائياً.
4. قبل GitHub شغّل `CHECK_WARQNA_WINDOWS.bat`.
5. في الإنتاج شغّل Laravel Scheduler كل دقيقة: `php artisan schedule:run`.
6. افحص الأمر دون تغيير بيانات: `php artisan warqna:competitive-tick --dry-run`.
7. راقب Exit Code وسجل Laravel عند تشغيل الدورة الفعلية؛ تظهر المراجع المتعثرة في `error_refs` دون تعطيل بقية عناصر الدفعة.

## مبدأ النزاهة

العميل لا يرسل فائزاً موثوقاً ولا يكتب MMR أو جدول البطولة أو الجوائز. النتيجة تُقرأ من حالة الغرفة التي اعتمدها محرك الخادم، ثم تُطبق مرة واحدة تحت قفل قاعدة البيانات. وجود Anti-cheat شديد يوقف الاعتماد آلياً وينقل المباراة إلى طابور المراجعة.
