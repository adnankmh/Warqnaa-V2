# عقد R14.2 — Secure Account & CI Reliability

- تغيير البريد وكلمة المرور متاح للمستخدم والمدير في Laravel وFlutter.
- كلمة المرور الحالية إلزامية لكل تغيير حساس.
- كلمة المرور الجديدة 8 أحرف على الأقل وتحتوي حرفًا كبيرًا وصغيرًا ورقمًا.
- تغيير البريد يلغي حالة التأكيد ويرسل رابطًا إلى البريد الجديد.
- تغيير بيانات الدخول يغلق جلسات API الأخرى ويحافظ على جلسة التطبيق الحالية.
- نموذج البروفايل القديم لا يستطيع تعديل بيانات الدخول.
- إعادة تشغيل Seeder لا تعيد بريد أو كلمة مرور Adnan وAbd للقيم الافتراضية.
- إصلاحات SQLite `:memory:` وGitHub Pages وحجم `public` محفوظة ومختبرة.
- جميع عقود R8–R14.1 تبقى إلزامية.
