# ابدأ هنا — Warqnaa R6.4 Build 640

هذه حزمة تراكمية تدمج R6.2 وR6.3 وR6.4 فوق baseline ‏R6.1 Build 610 دون الرجوع لأي Patch قديم.

## الجديد

- مركز لعب عالمي موحد: لعب سريع، غرف عامة، مجموعات، مشاهدة وRanked.
- متصفح غرف مباشر مع إنشاء غرفة ودخول آمن واستعادة حالة الاتصال.
- ربط Social World والمشاهدة والإعادات والأندية من التجربة الرئيسية.
- ربط المواسم وMMR والبطولات والمتصدرين والجوائز الخادمية.
- الحفاظ على متجر R6.1 وكل الطاولات وظهور الورق والمقتنيات والتفعيل.
- توافق كامل مع بيانات Build 610؛ لا تحذف قاعدة البيانات أو `.env`.

## التشغيل والتحقق

- Windows: `scripts/windows/current/START_WARQNA_V640_WINDOWS.bat`
- فحص Windows: `scripts/windows/current/CHECK_V640_WINDOWS.bat`
- Linux/macOS: `bash scripts/unix/current/check-v640.sh`

بيانات المدير تُمرر محليًا من متغيرات البيئة فقط ولا توضع في GitHub.
