# عقد R14 Global Release — 1.0.0+260

R14 يغلق خارطة Warqnaa عبر أربع قنوات: Backend، Web، Android وiOS. لا تعتبر النسخة عالمية ما لم تنجح القنوات الأربع، سلسلة R8–R14، Engine Gold، Laravel، Flutter، Docker، فحص الأسرار وSHA-256.

جاهزية المصدر لا تعني أن أسرار الإنتاج أو مفاتيح التوقيع أو حسابات المتاجر مرفقة. تبقى هذه عناصر نشر خارج المستودع. العربية والإنجليزية هما اللغتان المدعومتان، وجميع ميزات R8–R13 محفوظة.
