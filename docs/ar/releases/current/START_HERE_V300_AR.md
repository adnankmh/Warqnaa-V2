# ابدأ هنا — Warqnaa WORLD EXPERIENCE V1.1.0 Build 300

هذا هو الإصدار الكامل التراكمي فوق R14.3. يحافظ على إصلاحات Build 263 ويضيف WORLD EXPERIENCE: ست لغات، 15 ثيم، مركز لعب عالمي، Party system، reconnect/AFK lifecycle، مراقبة المشاهدة، توسعة التخصيص، WORLD OPS للإدارة، وتدقيق الاقتصاد والأمان.

قبل التشغيل على Windows استخدم `CHECK_WARQNA_WINDOWS.bat`. بعد نجاح الفحوصات استخدم `START_WARQNA_WINDOWS.bat` ثم ارفع المستودع نفسه إلى GitHub لتشغيل بوابات Backend / Android / Web / iOS.
