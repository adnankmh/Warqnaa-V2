# Warqnaa R7 — 1.9.0+700

المرجع المعتمد هو R6.5 في main، الالتزام `82bd3ba` بعد نجاح فحوص الخادم والويب وWindows. تُحفظ الألعاب والاقتصاد والواجهات السابقة.

R7 يضيف خادم تحقق معزولًا بحسابات مؤقتة، وفحص الدخول والتهيئة والهوية والمستوى وصلاحيات المدير، وشراء الزوج المجاني وتفعيله، والصداقة والغرفة واستعادة المقعد. يتضمن تحقق تسجيل الدخول على الويب وصفحة العروض ولوحة المدير وملفات PWA. لا يتصل الفحص بحسابات حقيقية.

أُغلق تسريب حالة الغرف الداخلية عبر bootstrap: يُرجع المسار الآن ملخصات الغرف العامة وغرف المستخدم فقط، دون حالة اللعب أو كلمة مرور الغرفة. تظل الأوراق الخاصة من مسؤولية مسار الجلسة المفلتر لكل لاعب.

يحفظ مسار R7 صورًا لشاشات Flutter بالعربية والإنجليزية عند 390×844 و844×390 و1280×800. الصور مأخوذة من محرك اختبار Flutter بخط مراجعة يدعم العربية؛ ليست شهادة مطابقة بصرية لكل جهاز. تُفحص تجربة Chrome كذلك في مسار Web القائم.

## الحزمة والتشغيل

بعد نجاح مسار R7 يظهر artifact باسم `warqnaa-r7-full-source` يحتوي حزمة المصدر والمثبت المرحلي وSHA-256. الحزمة مرتبطة بالالتزام الذي بناها. ليست APK أو IPA، وتحتاج تنزيل الاعتماديات أثناء التثبيت.

استخرج الحزمة خارج `D:\warq` وشغّل `INSTALL_WARQNAA_AUTO.bat`. تحتاج Windows وقرص D ومساحة كافية وPHP 8.2+ مع SQLite وmbstring وDOM وOpenSSL وPython 3.10+؛ يتولى المثبت تنزيل Composer بعد فحص التوقيع وFlutter عند غيابه إذا توفر Git. لا تحذف النسخة السابقة: المثبت يحفظ قاعدة SQLite والمرفوعات وبيانات الحساب ويحتفظ بنسخة احتياطية قبل التبديل. قواعد الإنتاج والخوادم الخارجية لا تُرقّى بهذه الأداة.

للتثبيت الأول فقط، تُزوّد بيانات المدير عبر متغيرات البيئة المحلية `WARQNAA_ADNAN_ADMIN_EMAIL` و`WARQNAA_ADNAN_ADMIN_PASSWORD`. لا تضعها في Git أو الأرشيف. الحساب الإداري الموجود لا يُعاد ضبطه.

المثبت يقرأ الإصدار ورقم البناء من الحزمة، ويحافظ على التوافق مع شكل حزم R6.5 السابق. بعد التثبيت يعمل `START_WARQNA_WINDOWS.bat` لإعادة التشغيل و`CHECK_WARQNA_WINDOWS.bat` لفحص المصدر.

## التحقق وحدوده

لتنفيذ فحص R7 على Linux من checkout نظيف دون `.env` أو إعدادات مخزنة، وبعد تثبيت الاعتماديات:

```sh
python3 tools/r7_runtime_smoke.py --flutter-review --report-dir /tmp/warqnaa-r7-review
```

ينشئ الأمر قاعدة بيانات جديدة في مجلد مؤقت وخادمًا على loopback ثم يحذف الحسابات وكلمات المرور المؤقتة عند الانتهاء. لا يرفع سجلات الخادم أو ملف بيانات الدخول ضمن النتائج. لا تعتبر وجود أدوات الفحص دليل نجاحها؛ حالة Actions وتقرير التنفيذ هما المرجع.

لا تشمل هذه المرحلة اعتماد المدفوعات الحقيقية، مفاتيح توقيع المتاجر، اختبار iOS على جهاز حقيقي أو اعتماد تثبيت Windows كامل على جهاز المستخدم. تبقى هذه متطلبات نشر منفصلة.
