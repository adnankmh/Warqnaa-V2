# ابدأ هنا — Warqnaa R14.2 Secure Account

الإصدار الحالي **1.0.2+262**، ترقية تراكمية فوق R14.1 Build 261 تحفظ R8–R14.1 كاملًا.

أضافت النسخة مركز أمان فعليًا للموقع والتطبيق لتغيير البريد وكلمة المرور بعد تأكيد كلمة المرور الحالية، وإغلاق الجلسات الأخرى، وإعادة تأكيد البريد الجديد. كما تمنع Seeders إعادة بيانات Adnan أو Abd إلى القيم الافتراضية.

على Windows شغّل `CHECK_WARQNA_WINDOWS.bat` ثم `START_WARQNA_WINDOWS.bat` واختر المنفذ 8007.
