# ابدأ هنا — Warqnaa R14.1 Legendary Experience

الإصدار الحالي هو **1.0.1+261**، ترقية تراكمية مباشرة فوق R14 Build 260. يحافظ على R8–R14 كاملًا ويضيف نقلة بصرية للموقع والتطبيق وإصلاحًا دائمًا لفشل حجم public في GitHub Actions.

على Windows شغّل CHECK_WARQNA_WINDOWS.bat للفحص، ثم START_WARQNA_WINDOWS.bat واختر المنفذ 8007 الموصى به. بعد التشغيل افتح http://127.0.0.1:8007.

لا تضع .env أو مفاتيح التوقيع أو أسرار الإنتاج في المستودع.
