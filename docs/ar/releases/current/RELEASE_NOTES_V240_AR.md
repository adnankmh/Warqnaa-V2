# ملاحظات إصدار Warqnaa R12 Build 240

**0.7.0+240 — Competitive Arena**

هذا الإصدار ينقل ورقنا من Social World إلى عالم تنافسي متكامل: Ranked/MMR، مواسم وتصنيفات، بطولات وجداول متعددة المراحل، بطولات أندية ودول، جوائز موسمية، وتجربة إدارة مستقلة.

أهم ضمانات النسخة:

- لا نتيجة أو MMR أو تأهل من العميل.
- لا Bots في Ranked أو غرف البطولة.
- مقعد المنسحب يبقى للاعب الحقيقي وقابلاً لإعادة الاتصال ولا يتحول إلى Bot.
- البحث عادل ثنائي الجانب ولا يسمح للاعب قديم غير متوافق بحجب لاعبين متوافقين خلفه.
- جداول 2/3/4/6 مقاعد تستخدم سعة صحيحة رياضياً، وتصبح غير قابلة لإعادة البناء بعد إصدار الغرف.
- التعادل أو إلغاء مباراة النزاهة ينتج غرفة حسم/استبدال خادمية موثقة بلا تأهل مكرر.
- لا دفع قبل النهائي ولا دفع مكرر.
- التسوية النهائية تعيد التحقق داخل القفل من الغرفة النهائية والأبطال والتسجيل قبل تحرير الجائزة.
- لا اعتماد عند وجود إشارة Anti-cheat شديدة قبل مراجعة الإدارة.
- الإدارة الكاملة متاحة عبر الويب وFlutter، ودورة الاسترداد تعزل الأعطال وتبلغ نظام المراقبة.
- لا حذف لأي ميزة من R8 حتى R11.

المسارات الجديدة الأساسية: `/competitive` و`/admin/competitive` و`/api/mobile/v1/competitive/*`.
