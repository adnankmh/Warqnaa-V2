# ابدأ هنا — Warqnaa R6.1 Build 610

هذه نسخة تراكمية مبنية مباشرة فوق baseline ‏R5.3/B305 الحالي. لا تعيد أي Patch قديم.

## الجديد

- Home احترافية ومتجاوبة، Profile كامل، Social Hub موحد، وتنقل جديد للهاتف وسطح المكتب.
- تفعيل 50 طاولة V173 عالية الدقة في المتجر.
- إنشاء 50 ظهر ورق مطابقًا للطاولات نفسها، مع الشراء والتفعيل والحفظ.
- الإبقاء على الطاولة وظهر الورق الرسميين المجانيين و12 ظهر V021 فنيًا.
- طبقة تصميم ويب R6.1 متجاوبة وتدعم حالات لوحة المفاتيح وتقليل الحركة.

## المدير

شغّل `scripts/windows/current/SETUP_ADNAN_PRIMARY_ADMIN.bat` وأدخل البريد وكلمة المرور محليًا. لا تُحفظ القيم السرية في GitHub أو في الملفات المتتبعة.

## التحقق

- Windows: `CHECK_WARQNA_WINDOWS.bat`
- Linux/macOS: `bash scripts/unix/current/check-v610.sh`
