# تقرير R6.5 Build 650

Baseline: 1.7.0+640. الإصدار: 1.8.0+650.

التغييرات تشمل تصحيح تكامل الغرف، إدارة مجموعات ذات معاملات وقفل للسعة، تقليل البيانات المعروضة للمجموعة، مركز تشغيل بصلاحيات محددة، وتثبيت مرحلي مع حفظ SQLite.

الاختبارات السلوكية المضافة:
- Laravel: رفض اللاعبين والمدير غير المخوّل؛ نبضة الجدولة الحالية والقديمة؛ حجب البريد؛ إعادة دخول مجموعة ممتلئة للعضو الحالي؛ رفض الدخيل؛ انتقال القيادة وإغلاق آخر مجموعة.
- Flutter: عرض فشل الاتصال بدل مؤشرات مختلقة؛ شاشة غرف بعرض 320 دون أخطاء عرض.
- Windows CI: تحليل PowerShell وقبول الحزمة الصحيحة ورفض اختلاف SHA-256.

بوابات التشغيل غير المنفذة في بيئة التجهيز تُذكر بصفتها NOT RUN في ملف النتائج. لا تعتبر هذه الاختبارات ناجحة بمجرد وجود ملفاتها.
