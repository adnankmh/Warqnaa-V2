# تقرير جودة R14.1 Build 261

النطاق: إصلاح CI، Laravel Web، Flutter، عقود R8–R14.1، Preflight وحزم Full/Upgrade.

## النتيجة

- نجحت دورة الإغلاق الكاملة من R8 حتى R14.1 دون إسقاط أي عقد سابق.
- نجح فحص R10 الموسّع بـ472 نتيجة؛ أصبح يتحقق من بصمة كل أصل محلي داخل manifest.
- عولج خطأ CI بفصل ميزانية مصدر `public` عن ناتج `public/build`، مع حد مستقل للمجموع المنشور.
- الأحجام المقاسة: المصدر 9.35 MiB، ناتج البناء المحلي 0 MiB، الإجمالي 9.35 MiB.
- نجح Global Release Preflight للقنوات الأربع، اللغتين، أصول المتاجر، Engine Gold وسياسة الأسرار.
- نجح التحقق الساكن: JSON=65، YAML=17، XML=2، DART=39، SOURCE_SCAN=574.
- نجح فحص بنية Dart والمراجع المحلية.

## حدود بيئة التحقق

لا تتوفر PHP/Composer وFlutter/Dart في بيئة الإغلاق المحلية؛ لذلك تبقى اختبارات Laravel وFlutter التنفيذية مفروضة داخل GitHub Actions عبر workflows الإصدار، ولا يدّعي هذا التقرير تشغيلها محليًا.
