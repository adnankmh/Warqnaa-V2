# تقرير جودة R7 Build 700

التغييرات الأساسية: حجب بيانات الغرف الداخلية عن bootstrap، احترام رؤية الغرف الخاصة، تحقق HTTP متكامل بحسابين، استعادة الحساب عبر Flutter من بيانات الخادم، صور مراجعة للشاشات، وحزمة مصدر ومثبت يقرآن بيانات الإصدار الحالية مع منع الرجوع إلى إصدار أقدم.

تُنفذ اختبارات PHP وFlutter وWindows في Actions لعدم توفر هذه الأدوات محليًا. لا تُسجل نجاحات مفترضة: راجع تقرير التنفيذ الفعلي وحالة الالتزام في GitHub. الفحص البصري للصور مطلوب بعد إنتاجها.

لا تشمل الشهادة التشغيل على جهاز المستخدم أو خادم الإنتاج أو توقيع iOS أو الدفع الحقيقي. حسابات الاختبار صناعية وصورها بخط مراجعة موثق؛ لا تُستخدم بيانات مدير حقيقية.
