# تقرير جودة R13 Build 250

## خلاصة

R13 يغلق طبقة اعتماد المحركات فوق R12: 20 محركاً، ثلاثة ملفات اعتماد، ثمانية ثوابت جودة، تقرير JSON، واختبار Laravel ثابت.

## البوابات

- الفحص المحلي: 25 مباراة لكل محرك عند توفر PHP.
- Release CI: 2,000 مباراة لكل محرك.
- Scheduled CI: 5,000 مباراة لكل محرك.
- سلسلة عقود R8/R9/R9.1/R10/R10.1/R11/R12/R13.
- Laravel PHPUnit وFlutter analyze/test/build تبقى إلزامية في GitHub Actions.

لا تُسجّل اختبارات PHP/Flutter كناجحة محلياً إذا لم تكن runtimes مثبتة؛ نتيجة CI هي المرجع التنفيذي النهائي.
