# R9 — استوديو Adnan المحلي وصالة الألعاب

التاريخ: 28 سبتمبر 2026.
قاعدة التعديل البعيد: `8309e100a975eac854f1d63e19b702fcb87c68ef`، PR #7.

## التغيير

- زر مستقل «إدارة Adnan • دون إنترنت» يعمل دون إنشاء حساب خادم أو إدخال كلمة مرور خادمية.
- الدور `local_admin` مختلف عن `primary_admin`. لا يمنح هذا المدخل صلاحية الإدارة على الخادم، ولا يغيّر بيانات اعتماد حساب Adnan المتصل.
- يتم مسح رمز الجلسة ومعرّف المستخدم وإيقاف مراقبة الاتصال عند الانتقال، ورفض استجابات bootstrap القديمة بعد تغيير الجلسة.
- بيانات اللعب المحلية ضمن `warqna.device-admin.adnan.`، منفصلة عن بيانات حساب Adnan المحفوظ من الخادم.
- استعادة الحساب والمفضلة عند إعادة فتح التطبيق. الضيف والتسجيل المحلي العادي لا يرثان دور الإدارة المحلية.
- استوديو محلي للمظهر والألوان والخط والأزرار، المفضلة، صور الطاولة وظهر الأوراق، الصوت ومؤثرات الطاولة.
- صالة الألعاب تعرض الكتالوج المحلي كاملًا مع البحث بالعربية والإنجليزية، وتصنيفات المفضلة والطرنيب والتركس والهاند والبناكل، وحالة فارغة قابلة للاستعادة.
- شريط يوضح اللعب المحلي/المتصل، ومدخل مباشر لاستوديو Adnan من الرئيسية.

## حدود التحقق

نجح فحص المصدر الشامل `tools/validate_release.py`، وفحص توصيل الرئيسية `tools/test_home_successor_contract.py`، و`git diff --check`.

أُضيفت سبعة اختبارات سلوكية جديدة: فصل بيانات الحساب والجلسة، منع انتقال الدور للضيف والتسجيل العادي، استعادة الجلسة المحلية، فتح الاستوديو وتغيير إعداد فعلي باللغتين، والبحث والتصنيفات واستعادة النتائج باللغتين.
**لم تُشغَّل هذه الاختبارات بعد**: Flutter/Dart غير مثبتين في بيئة العمل الحالية. لم يُبنَ APK جديد ولم تجر مراجعة مرئية لهذه الدفعة.

## حالة الرفع والموافقة

تم التحقق عبر GitHub من أن المستخدم المتصل `adnankmh` هو مالك المستودع العام وله صلاحية admin/push. قُبل إنشاء tree للتعديلات، لكن المراجعة الآلية رفضت `create_commit`، حتى بعد استرجاع الموافقة الصريحة السابقة من سياق المحادثة. سبب الرفض: المراجعة تطلب موافقة مستخدم مباشرة في هذه المحادثة ولا تعتمد دليل السياق المسترجع لهذه الخطوة. ثم قدّم المستخدم موافقة مباشرة على نشر تحديث R9 واختباراته في المستودع العام وعلى الفرع نفسه، بتاريخ 28 سبتمبر 2026. تجري متابعة الرفع والاختبارات بناءً عليها؛ تُحدّث النتائج بعد اكتمالها.
