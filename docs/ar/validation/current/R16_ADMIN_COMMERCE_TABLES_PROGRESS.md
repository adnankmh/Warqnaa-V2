# R16 — Admin / Commerce / Voice / Responsive Tables

الرأس الأب المعتمد قبل R16 هو R15 (`56452c265b355abdda7dddf46a977fd4d2153840`).

تضيف هذه الدفعة طبقة موحدة لحساب `primary_admin` تعتمد على الدور الخادمي لا على اسم المستخدم، وتحافظ على المستوى 99 وPasha لمدة 36500 يومًا واحتياطي توكنز BIGINT آمن أعلى بكثير من 99,999,999,999,999,999، مع استمرار منطق WalletService بعدم إنقاص رصيد المدير الأساسي. كما أصبح لكل مقتنى حقل كمية؛ تضمن حالة المدير 100 نسخة على الأقل من كل مقتنى فعال غير التذاكر والباشا، و100 تذكرة على الأقل من كل فئة معروفة.

في التجارة الحقيقية يبقى العميل غير موثوق: لا تمنح مكافأة الشراء إلا بعد تحقق خادمي. أضيف مسار Stripe PaymentIntent للويب ومسار Trusted Verifier موقّع لـGoogle Play / Apple / Web، مع إبقاء المفاتيح والأسرار خارج Git.

الصوت يحتفظ ببنية WebRTC وإشاراته الخادمية، مع قائمة STUN أوسع، بينما يبقى TURN سر نشر خارجي مطلوب للموثوقية الإنتاجية بين الشبكات المقيدة. اللعب الجماعي يحتفظ بالـserver-authoritative heartbeat/reconnect/parties ويعرض جاهزية الـruntime العامة دون كشف أسرار.

الطاولة على الويب أصبحت تضبط نفسها بشكل مستقل للهاتف العمودي والـdesktop/landscape، مع احتواء رسومات الطاولة بعيدًا عن الورق والمقاعد. وفي Flutter أصبحت أحجام اليد ومقاعد اللاعبين تتكيف مع مساحة الشاشة بدل الاعتماد على قياسات ثابتة.

الفحص المحلي قبل GitHub نجح في PHP syntax، clean-root، WORLD EXPERIENCE contract، و`tools/validate_release.py` الكامل لـv700. تبقى GitHub Actions المرجع النهائي لاعتماد Laravel runtime وFlutter/Web/Android والمراجعة المرئية.
