# R10 — مراجعة الطاولات المحلية

تاريخ العمل: 28 سبتمبر 2026. القاعدة البعيدة: `ad901b4d65c774b69fc5b6a5a01cee206b79b44f`، فرع `codex/r8-play-experience`، PR #7.

## الحالة المؤكدة عند البداية

- R9 سلّم بالفعل؛ فحوصه الخمسة ناجحة، بما فيها Android 36379277783. لا تكرر تسليمه.
- لا يوجد بناء نشط للرأس المرجعي. أنشئ worktree مستقلًا لحماية التعديلات السابقة في النسخ المحلية الأخرى.
- تغييرات هذه الدفعة: إصلاح نصوص التحكم باللعب واختيار الطلب والحكم والعقد في الإنجليزية، وقبول رمز الحكم المختصر الذي يستخدمه المحرك المحلي.
- إضافة مصفوفة عرض للألعاب المحلية الاثنتي عشرة × لغتين × أربعة مقاسات، من حساب Adnan المحلي، وحفظ صور فعلية في artifact المراجعة.

## التحقق

فحص المصدر نجح. اختبارات Flutter الجديدة والصور **بانتظار CI**. أوقفت المراجعة الآلية إعداد Flutter المحلي بسبب محاولة وصول إلى instance metadata، واختير GitHub Actions المعزول بدل محاولة تجاوز الرفض.

## الخطوة التالية

1. تحقق من أحدث PR/head وبنائه قبل أي رفع جديد. افحص نتائج `r10_local_tables_test.dart` وصور `local-tables`، وعالج أي overflow مثبت.
2. مواقع مقاعد الطاولة العامة ما زالت ثابتة؛ راجع الوضع الأفقي خصوصًا. اختبر تفاعل اختيار ورقة ورميها وطلب العقد من الأزرار الفعلية.
3. لا تعتمد اكتمال مصفوفة العرض كاختبار لجولة كاملة في كل لعبة. لا تدّع اكتمال ترجمة جميع رسائل المحرك.
4. بعد نجاح الفحوص، طابق APK ببصمة المحاكي وأتح نسخة جديدة فقط عند اكتمالها.

الخادم العام وتوقيع المتجر والهاتف الحقيقي ونشر الموقع ما زالت أمورًا غير مكتملة. لا دمج إلى main ولا نشر إنتاجًا ولا شراء. دور local_admin يبقى محليًا دون كلمة مرور إدارية خادمية.
