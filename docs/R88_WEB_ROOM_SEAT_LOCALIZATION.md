# R88 — bilingual room seats

R88 localizes the server-rendered room seat state for Arabic and English:
player and placeholder accessibility names, bot/connection state, Pasha
replacement controls, per-player voice controls, round statistics, empty-seat
actions and the seat-lock notice.

This is a presentation-only change. Room ownership checks, Pasha eligibility,
replace-player and join routes, voice behavior, seat assignment, game engines,
networking, economy and permissions remain unchanged.
