# Warqnaa R43 — تحويل الشاشات المرجعية إلى واجهات برمجية

المصدر: مجموعة الصور المرجعية 01–14 التي اعتمدها صاحب المشروع بتاريخ 21 أكتوبر 2026. الصور دليل بصري فقط، **وليست صورًا موضوعة فوق الأزرار**. جميع إجراءات الشراء واللعب والجوائز تستمد البيانات من النظام القائم.

## دليل الشاشات

| المرجع | واجهة الويب | واجهة Flutter | الربط الحقيقي |
|---|---|---|---|
| 01 الرئيسية – الموقع | `resources/views/home.blade.php` + R43 CSS | `R35ReferenceWorldDashboard` | الألعاب، البطولات، الأندية، المتجر |
| 02 الرئيسية – الهاتف | شبكة 3 أعمدة في أحجام الهواتف | `B307HomeDashboard` + R43 quick destinations | التنقل الرئيسي والملف الشخصي |
| 03 طاولة اللعب | `.game-table`, `.hand-row .card` | غرفة اللعب الحالية ومحركات الألعاب | إجراءات اللعب والخادم كما كانت |
| 04 المتجر | الواجهات الحالية + قواعد R43 العامة | `StorePage` والتبويب `onTab(0)` | مقتنيات ورصيد وأسعار حقيقية |
| 05 جميع الألعاب | `games/index.blade.php` وشبكة متجاوبة | `R51FeaturedGamesAndTournaments` و `GamesPage` | `showGameLobby` و `rooms.index` |
| 06 البطولات | `.w36-tournaments` وبيانات الأحداث الفعلية | `R12CompetitiveArenaPage` | شروط التسجيل والجوائز حسب الخادم |
| 07 الأندية | `.w36-clubs` | `ClubsPage` | العضوية والمجموعات القائمة |
| 08 تخصيص الملف | `.w36-profile` | `showAvatarPicker` / `showProfile` | الصورة والإطار والغطاء |
| 09 الإيموجي | `.w36-reactions` | صفحة المتجر الحالية | باقات وتفاعل الغرفة الأصلي |
| 10 الروبوتات | `.w36-bots` | اختيار اللعبة والتدريب المتاح | **لا يتم اختراع روبوت أو محرك غير موجود** |
| 11 خلفيات الورق | متجر المقتنيات الحالي | المتجر ومكتبة الأصول القائمة | الخلفيات المرخصة والموجودة |
| 12 المعززات | المتجر الحالي | قسم المتجر والمعززات | حالة الرصيد والتفعيل وفق المنطق الحالي |
| 13 الحسابات التجريبية | النظام الحالي للمصادقة | تسجيل الدخول الحالي | **عدم تضمين كلمات مرور داخل الواجهة أو Git** |
| 14 معلومات عامة | المحتوى التعريفي الحالي | شاشات المعلومات القائمة | لا تغيير في شروط الخدمات |

## الملفات المعدلة

- `backend-laravel/public/assets/css/r43-reference-screens.css` — نظام التصميم المتجاوب.
- `backend-laravel/resources/views/layouts/app.blade.php` — تحميل CSS بعد القواعد السابقة.
- `flutter_app/lib/r35_reference_world.dart` — شبكة ست ألعاب، الوجهات التفاعلية الجديدة.
- `flutter_app/lib/b307_visual_revolution.dart` — إظهار الوجهات نفسها على الهاتف.
- اختبارات Flutter وLaravel للتوافق، المحاذاة RTL/LTR، وقابلية النقر.
  
## معايير الجودة

- لا تغييرات في حساب النقاط أو محركات الهاند والبناكل أو المكافآت أو صلاحيات الإدارة.
- 3 بطاقات في الصف على الهاتف القياسي، و6 بطاقات على عرض سطح المكتب، مع انهيار إلى عمودين للشاشات الضيقة جدًا.
- عدم إيقاف البحث والتصفية والنسق المضغوط في صالة الألعاب.
- تباين النصوص، حدود ضغط مرئية، دعم الحركة المخففة، وعدم اقتطاع المساحات في الوضع العمودي.
- مراجعة `flutter test` و `php artisan test` والبناء في GitHub Actions قبل الدمج.

## حالة التنفيذ

هذا الدمج يغطي **لغة التصميم والربط الفعلي في الصفحات الموجودة**، ولا يعني أن محركات اللعب أو جميع شاشات الحساب قد أُعيد بناؤها أو أن درجة التطابق البصري 100%. التحقق النهائي يحتاج تشغيل الويب وAndroid وقياس كل شاشة مقابل المرجع على الأجهزة المستهدفة.
