# R18 Visual Luxury

This increment moves the real Android/Web lobby toward the approved Warqnaa visual direction while keeping all game engines and multiplayer contracts untouched.

## Included
- Deep navy glass lobby with cyan/gold accents.
- Responsive Warqnaa brand header for narrow phones through desktop web.
- Tournament hero wired to the existing competitive arena.
- Quick-play table presentation with responsive card art.
- Game tiles with distinct palettes for Tarneeb, Trix, Hand, Banakil, Baloot and Basra, using the shipped R101 game artwork.
- Discovery surfaces for Arabic avatars, animated/voiced reactions and glow boosters.
- Existing rooms, parties, store, social and tournament navigation remain wired to their real routes.
- Existing card-hand minimum touch/readability geometry and table-seat semantics remain unchanged.

## Design rule
Jawaker is a quality/feature benchmark only. Warqnaa keeps original branding, layouts, art and interaction styling.

## Validation
`tools/test_r18_visual_luxury_contract.py` protects the R18 visual hooks and the pre-existing R8 card interaction invariants. Full Flutter/Web/Android/runtime validation remains authoritative in GitHub Actions before merge.
