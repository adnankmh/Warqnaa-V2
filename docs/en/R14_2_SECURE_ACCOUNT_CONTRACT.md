# R14.2 Secure Account & CI Reliability Contract

Build 262 adds authenticated email and password changes to Laravel Web and Flutter. Every sensitive change requires the current password. New email addresses become unverified and receive a verification link; other API sessions are revoked while the current mobile session remains active. Legacy profile updates cannot bypass the security center, and seeders never overwrite changed Adnan or Abd credentials. R8–R14.1 regression, SQLite memory, Pages fallback and R10 asset budgets remain mandatory.
