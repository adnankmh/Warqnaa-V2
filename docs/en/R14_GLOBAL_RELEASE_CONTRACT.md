# R14 Global Release Contract — 1.0.0+260

R14 closes the Warqnaa roadmap across backend, web, Android and iOS. A global release requires all four channel gates, the R8–R14 chain, Engine Gold, Laravel, Flutter, Docker, secret policy and SHA-256 evidence.

Source readiness does not embed production secrets, signing keys, store credentials or DNS/TLS control. Those remain deployment-owned. Arabic and English are the supported product locales; every R8–R13 feature remains preserved.
