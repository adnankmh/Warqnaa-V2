# R87 — bilingual special room states

R87 completes the remaining server-rendered room labels for Arabic and English:
away-mode controls, leave confirmation, the center status grid, bid and trump
controls, backgammon and domino actions, and the optional voice-room panel.

This is a presentation-only change. Route names, action identifiers, payloads,
voice pricing, room-exit limits, latest-state validation, hidden cards, game
engines, networking, economy and permissions remain unchanged.
