# R75 — friendly-room setup theme propagation

R75 closes the fixed-palette gap in friendly match creation. Normal/voice mode
cards and the participant, invitation and computer-player panel now derive their
surface, borders, readable text and depth from the selected cosmetic theme.

The navigation callback from mode selection to room setup is exercised directly.
Player capacity, invited-user IDs, computer-player count, open seats, room
options, server authority, permissions and economy are unchanged.

Arabic RTL and English LTR widget coverage exercises dark crimson and light
emerald themes at 390×844. R7 captures all four participant-setup states for
manual visual review.
