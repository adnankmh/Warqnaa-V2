# R73 — shared room-tool theme propagation

R73 closes the next shared gameplay-theme gap after R69–R72. The compact
`RoomTool` buttons used by local and server-backed tables still painted the
fixed sky-luxury panel palette regardless of the selected cosmetic theme.

Their background gradient, border and shadow now derive from
`R69PlaySurfaceColors`. The icon keeps the established warm-gold hierarchy while
blending with the selected accent. Tool size, keys, callbacks, room permissions,
engine state, server actions and economy are unchanged.

Arabic RTL and English LTR widget coverage exercises dark crimson and light
emerald themes at 390×844. R7 captures all four states for manual visual review.
