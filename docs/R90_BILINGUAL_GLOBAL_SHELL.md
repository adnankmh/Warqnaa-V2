# R90 — bilingual global Laravel shell

R90 gives the server-rendered Laravel shell an Arabic/English contract before
client-side scripts run. The global navigation, games curtain, localized game
names and play modes, theme and language panels, Pasha status, token ledger,
theme/language buttons and volume control now follow the active locale and
document direction.

The update preserves routes, game catalog data, theme identifiers, preference
handlers, inventory/economy values, authorization and gameplay behavior. It
only changes labels, accessible names and locale selection for existing data.
