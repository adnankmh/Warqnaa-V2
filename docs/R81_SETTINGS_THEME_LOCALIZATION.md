# R81 — bilingual themed settings center

R81 groups gameplay, identity, accessibility and system settings into panels
derived from the selected cosmetic theme. The save action and non-semantic
security accents follow the same palette, while connected status, destructive
account actions and protected-administrator warnings retain semantic colors.

Previously Arabic-only gameplay, connection, installation, recovery and
administrator descriptions now render in Arabic or English. Setting values,
callbacks, orientation behavior, asset delivery, permissions, credentials,
networking, game engines and economy authority are unchanged.

Arabic and English widget coverage exercises dark crimson and light emerald
themes at 390×844. R7 captures the top and system portions in all four
locale/theme combinations for manual review.
