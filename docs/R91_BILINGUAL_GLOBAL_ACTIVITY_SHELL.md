# R91 — bilingual global activity shell

R91 completes the server-rendered Arabic/English contract for the global
activity controls that remain visible across Laravel screens. Club updates,
game invitations, competitions, notification actions, chat tabs and search,
sound, the active-room shortcut, leave/logout confirmations and the install
prompt now follow the active locale before client-side translation runs.

Accessible names are included for notification shortcuts, chat-window controls,
sound and message inputs. Existing routes, notification records, chat modes,
room leave limits, theme identifiers, economy, authorization and gameplay are
unchanged.
